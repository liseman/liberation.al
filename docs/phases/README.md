# Historical hardware designs

These October 2026 proposals are unimplemented design references, not installation
instructions or current product status:

- [Ambient sensors](PHASE2_AMBIENT_SENSING.md): a microcontroller, environmental sensors, and haptics.
- [Projection](PHASE3_PROJECTION.md): depth-assisted projection and surface calibration.
- [SLAM](PHASE5_SLAM.md): a satellite camera and inertial mapping proposal.

Their hardware specifications, APIs, sketches, and performance targets were not
validated. Named prototype scripts are not present in this repository. Recheck
those assumptions before starting an implementation.

The obsolete mock bench, voice, face-recognition, and panorama recipes were removed;
they were removed. Phase numbers differ from the
[original plan](../history/plan-2026-10.md). See [Architecture](../ARCHITECTURE.md)
for the running system and [Roadmap](../ROADMAP.md) for planned work.
